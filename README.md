## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Ruins of Dawn**. This trainer adds optional gameplay assistance for Ruins of Dawn, including improved survivability, faster progression, enhanced combat output, and greater control over loot-focused activities. It is designed for the game's Warrior, Mage, and Warlock classes, random-affix equipment, forging system, rifts, ruins, trials, elite enemies, and boss encounters.

**Target Audience:** Players who want a more relaxed experience, faster character progression, easier boss attempts, quicker loot farming, or convenient testing of Warrior, Mage, and Warlock builds.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## ⚡ Features (v1.0)

### 🎯 Gameplay

- **Invincible Player** — Prevents the player character from being defeated during exploration and combat.
- **Unlimited Combat Resource** — Keeps the character's usable combat resource available for repeated skill usage.

- **Damage Multiplier** — Raises outgoing damage to help clear enemies and complete challenging encounters faster.
- **One-Hit Defeat** — Allows regular enemies to be defeated with a single successful attack.

### 🧰 Inventory

- **Loot Drop Multiplier** — Improves the quantity of equipment and rewards obtained during loot-focused activities.
- **Forging Assistance** — Provides additional support while improving gear through the game's forging system.

## 📖 Detailed Feature Guide

### Movement & Exploration

Start the game and load a character before enabling movement-related options. Use the movement speed toggle while traveling between the starting village, combat zones, ruins, rifts, and trials. Return the value to normal before interacting with menus or transitioning between areas if movement behaves unexpectedly.

### Tools & Inventory

Use loot and forging options after entering active gameplay rather than from the title screen. Collect equipment normally, then enable the relevant trainer function before clearing additional encounters or improving gear. Confirm important items and forged equipment manually, and create a backup save before experimenting with large quantities of rewards.

### World & Environment

Ruins of Dawn begins in a starting village and sends the player into a demon-infested continent filled with monsters, elite enemies, bosses, ruins, rifts, trials, and special encounters. Progress through the world normally, enabling experience or loot assistance only when needed. Disable all options before saving, changing areas, or joining a co-op session.

### Combat & Weapons

Load into an active encounter before enabling combat functions. Invincibility protects the player during difficult fights, while damage and one-hit options accelerate ordinary enemy and boss battles. Fast skill recovery is useful for testing class abilities, but combat values should be restored before cooperative play or when checking unmodified build performance.
